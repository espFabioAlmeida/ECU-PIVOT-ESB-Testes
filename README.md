# ECU-PIVOT-ESB-Testes
Projeto Automasensr: ECU-PIVOT-ESB-Testes

# Escopo
Realiza testes na placa ESB para o programa da ECU-Pivot-ESB. <br>
As comunicações não são testadas. <br>
A placa realiza testes apenas de eeprom, relés, entradas digitais, chaves tácteis, display lcd, leds indicativos, buzzer e entrada analógica. <br>
Tudo é apresentado no display. <br>
Os relés acinam 1 por vez a cada segundo. <br>
